### 10. Practice: Build Your First Multi-File Project

You've now seen every building block of Chapter 1: the compiler, the anatomy of a program, headers, the preprocessor, compilation and linking, common errors, the command line, and a minimal project layout. It's time to combine them into one small but complete project.

You'll build a tiny program made of **three modules** (greeter, calculator, and entry point), wired together with headers and a Makefile, just like a real C codebase.

#### Project Overview

The project will:

* Print a greeting using a `greet()` function in a separate module
* Perform a few arithmetic operations using a `calc` module
* Tie everything together in `main.c`
* Build with a Makefile and `gcc`

#### Project Structure

```
hello_calc/
├── include/
│   ├── greet.h
│   └── calc.h
├── src/
│   ├── greet.c
│   └── calc.c
├── main.c
└── Makefile
```

#### Split Into Modules

**include/greet.h**

```c
#ifndef GREET_H
#define GREET_H

void greet(const char *name);

#endif
```

**src/greet.c**

```c
#include <stdio.h>
#include "greet.h"

void greet(const char *name) {
    printf("Hello, %s!\n", name);
}
```

**include/calc.h**

```c
#ifndef CALC_H
#define CALC_H

int add(int a, int b);
int sub(int a, int b);
int mul(int a, int b);

#endif
```

**src/calc.c**

```c
#include "calc.h"

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }
```

**main.c**

```c
#include <stdio.h>
#include "greet.h"
#include "calc.h"

int main(void) {
    greet("C Learner");
    printf("2 + 3 = %d\n", add(2, 3));
    printf("7 - 4 = %d\n", sub(7, 4));
    printf("6 * 5 = %d\n", mul(6, 5));
    return 0;
}
```

**Makefile**

```makefile
CC = gcc
CFLAGS = -Wall -Wextra -Iinclude
SRC = main.c src/greet.c src/calc.c
OUT = hello_calc

$(OUT): $(SRC)
	$(CC) $(CFLAGS) $(SRC) -o $(OUT)

clean:
	rm -f $(OUT)
```

#### Build and Run

```bash
make
./hello_calc
```

Expected output:

```
Hello, C Learner!
2 + 3 = 5
7 - 4 = 3
6 * 5 = 30
```

#### What You Practised

Building this small project exercises every idea from Chapter 1:

* **Anatomy** — every file is a small, well-formed C program with `#include`, functions, and statements.
* **Headers and the preprocessor** — `greet.h` and `calc.h` declare what exists; the `.c` files define it.
* **Compilation and linking** — each `.c` file becomes an object file, and the linker stitches them together.
* **Errors and warnings** — `-Wall -Wextra` keeps the build honest.
* **Command line** — `make`, `./hello_calc`, and `make clean` all happen in the shell.
* **Project structure** — `include/`, `src/`, and a single `main.c` keep things tidy.

#### Try It Yourself

1. Add a `div(int a, int b)` function to the `calc` module that prints an error if `b == 0`.
2. Add a `farewell(const char *name)` function to a new `farewell` module and call it at the end of `main`.
3. Break the build on purpose: drop a `#include`, misspell a header name, or remove a `;`. Read the error carefully and fix it.
4. Run `gcc -E main.c -Iinclude | less` and find where the headers expand.
5. Add `-O2` to `CFLAGS` and rebuild. Compare binary sizes with `ls -l`.

You've just taken your first real C program from a single file to a structured, multi-module build, the same shape used in everything from small CLI tools to the Linux kernel.
